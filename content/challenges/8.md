## Code samples

Each sample implements the "Route refund" node of a design, in the three languages Subtubes highlights.

### Python

```python
def route_refund(payload: dict) -> dict:
    # Implements the "Route refund" node.
    if not payload.get("id"):
        raise ValueError("id is required")
    return {"id": payload["id"], "status": "done"}
```

### TypeScript

```ts
interface Payload {
  id: string;
}

// Implements the "Route refund" node.
export function routeRefund(payload: Payload): { id: string; status: "done" } {
  if (!payload.id) throw new Error("id is required");
  return { id: payload.id, status: "done" };
}
```
