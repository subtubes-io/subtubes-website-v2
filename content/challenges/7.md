## Code samples

Each sample implements the "Check limit" node of a design, in the three languages Subtubes highlights.

### Python

```python
def check_limit(payload: dict) -> dict:
    # Implements the "Check limit" node.
    if not payload.get("id"):
        raise ValueError("id is required")
    return {"id": payload["id"], "status": "done"}
```

### TypeScript

```ts
interface Payload {
  id: string;
}

// Implements the "Check limit" node.
export function checkLimit(payload: Payload): { id: string; status: "done" } {
  if (!payload.id) throw new Error("id is required");
  return { id: payload.id, status: "done" };
}
```
