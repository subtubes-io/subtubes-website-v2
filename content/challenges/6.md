## Code samples

Each sample implements the "Create order" node of a design, in the three languages Subtubes highlights.

### Python

```python
def create_order(payload: dict) -> dict:
    # Implements the "Create order" node.
    if not payload.get("id"):
        raise ValueError("id is required")
    return {"id": payload["id"], "status": "done"}
```

### TypeScript

```ts
interface Payload {
  id: string;
}

// Implements the "Create order" node.
export function createOrder(payload: Payload): { id: string; status: "done" } {
  if (!payload.id) throw new Error("id is required");
  return { id: payload.id, status: "done" };
}
```

### Terraform

```terraform
variable "environment" {
  type    = string
  default = "staging"
}

# Infrastructure behind the "Create order" node.
resource "aws_dynamodb_table" "orders" {
  name         = "orders-${var.environment}"
  billing_mode = "PAY_PER_REQUEST"
  hash_key     = "id"

  attribute {
    name = "id"
    type = "S"
  }
}
```
