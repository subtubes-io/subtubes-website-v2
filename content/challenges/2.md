## Code samples

Each sample implements the "Open project" node of a design, in the three languages Subtubes highlights.

### Python

```python
def open_project(payload: dict) -> dict:
    # Implements the "Open project" node.
    if not payload.get("id"):
        raise ValueError("id is required")
    return {"id": payload["id"], "status": "done"}
```

### TypeScript

```ts
interface Payload {
  id: string;
}

// Implements the "Open project" node.
export function openProject(payload: Payload): { id: string; status: "done" } {
  if (!payload.id) throw new Error("id is required");
  return { id: payload.id, status: "done" };
}
```

### Terraform

```terraform
variable "environment" {
  type    = string
  default = "staging"

# Infrastructure behind the "Open project" node.

  bucket = "projects-${var.environment}"

```
